# ELOHIM 777 PAD

Windows app for a PlayStation 4 DualShock pad, and for other controllers Windows already understands.

- USB: plug the pad in with a data cable.
- Bluetooth: hold Share and the PS button until the light flashes, then pair it from Windows Bluetooth settings. The app opens that page.
- Button map: each button can be a mouse click, a scroll, or a keyboard key.
- The DualShock 4 touchpad moves the Windows pointer. A tap clicks. The touchpad button is a left click in the desktop map.
- Other pads (Xbox and most USB or Bluetooth gamepads) use the same button map. Their left stick can move the pointer.

The installer can run as administrator. Restart as administrator from the app if Windows will not hand over the pad.
